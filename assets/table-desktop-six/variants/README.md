# Varianti dei dorsi desktop a sei posti

`top/adelinda.png` e `lower_right/adelinda.png` derivano dai dorsi realmente
visibili nella diagnosi fornita dall'utente `diagnosi-carte-1793973486050.json`.
Il fotogramma originale è conservato in
`tests/fixtures/adelinda-six-chip-stack.jpg`. Le immagini sono estratte dopo
la registrazione del tavolo e normalizzate alla larghezza canonica di 1762 px.
Sono riferimenti aggiuntivi per le sole posizioni indicate, non carte generate
o annotazioni di identità delle carte coperte.
